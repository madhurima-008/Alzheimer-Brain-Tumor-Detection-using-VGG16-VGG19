# Alzheimer Brain Tumor Detection using VGG16 & VGG19

This project is a deep learning–based medical image analysis system designed for Alzheimer brain tumor detection using VGG16 and VGG19 transfer learning models. The system processes DICOM MRI brain scans, performs image preprocessing and normalization, and classifies images into Normal and Alzheimer Brain Tumor categories.

The application includes a GUI built with Tkinter that allows users to:

* Upload DICOM MRI datasets
* Preprocess and normalize images
* Train VGG16 and VGG19 models
* Compare model performance
* Predict tumors from MRI scans in real time

The project uses TensorFlow/Keras for deep learning model implementation and evaluates performance using:

* Accuracy
* Precision
* Recall
* F1-Score
* Confusion Matrix
* Training Accuracy Graphs

Technologies Used:-

* Python
* TensorFlow / Keras
* OpenCV
* Tkinter
* NumPy
* Scikit-learn
* Matplotlib & Seaborn
* PyDICOM

Objective:-

The main objective of this project is to apply transfer learning techniques for automated MRI brain scan classification and assist in early-stage medical diagnosis through deep learning–based tumor detection.
